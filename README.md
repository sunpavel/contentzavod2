# 🏭 Content Zavod — автоматизация коротких видео на n8n

Контент-завод на **n8n**: генерирует/публикует вертикальные ролики (Shorts/Reels/Threads)
на **YouTube + Instagram + Threads** и учится на метриках. Заточен под продвижение
продукта **FoodGenius AI** (AI-план питания + список покупок в Telegram).

## Что это

Замкнутый цикл, управляемый через Google Sheets (строка = ролик):

```
ТРЕНДЫ → ИДЕЯ → СЦЕНАРИЙ → AI-ВИДЕО → ТЕКСТЫ → ПУБЛИКАЦИЯ → АНАЛИТИКА ─┐
   ▲                                                                    │
   └──────────────── петля обучения (что зашло → приоритет) ◄───────────┘
```

- **Публикация** — через агрегатор (upload-post / Blotato), без Meta App Review.
- **Генерация видео** — fal.ai (Veo/Kling) + Creatomate, с лимитом трат.
- **Режим** — автопилот + утренний дайджест в Telegram с кнопкой 🚫 стоп.

## Структура репозитория

```
docker-compose.yml      self-hosted n8n + Postgres
.env.example            все ключи/настройки
config/channel-dna.yaml «ДНК» канала (тон, аудитория, форматы, хуки) — ядро
prompts/                промпты LLM (тренды / сценарий / тексты)
sheets/                 CSV-шаблон панели управления
workflows/              7 воркфлоу n8n (импортируемые JSON)
docs/                   архитектура, сетап, доступы, схема Sheets, контент-стратегия
```

### Воркфлоу
| WF | Файл | Делает |
|----|------|--------|
| WF1 | `wf1-trends.json` | тренды → идеи (status=idea) |
| WF2 | `wf2-script.json` | идея → хук+сценарий+шот-лист (scripted) |
| WF3 | `wf3-generation.json` | shot-list → fal.ai → Creatomate (produced) |
| WF4 | `wf4-captions.json` | тексты под YT/IG/Threads (queued) |
| WF5 | `wf5-publish.json` | публикация через upload-post (published) |
| WF6 | `wf6-analytics.json` | метрики → perf_score → обучение |
| WF7 | `wf7-digest.json` | дайджест + kill-switch в Telegram |

## Быстрый старт

```bash
cp .env.example .env      # впиши ключи (см. docs/02-credentials.md)
docker compose up -d      # n8n на http://localhost:5678
```
Затем: создай Google-таблицу (`docs/03-google-sheets.md`), импортируй воркфлоу из
`workflows/`, подставь credentials. Подробно — `docs/01-setup.md`.

> Рекомендация: запускай по этапам. Сначала **WF5** на готовом MP4 (MVP-публикация),
> потом наращивай генерацию и петлю аналитики. Первые 1–2 недели смотри дайджест глазами.

## Главный принцип

**Дистрибуция важнее производства.** Завод — инструмент, а не стратегия. Поэтому
тренд-ресёрч (WF1) и петля аналитики (WF6) — не опция, а ядро: без них лента
штампует в никуда. Узкий угол + сильный хук + явная польза → переход в бота.
