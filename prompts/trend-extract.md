# Промпт: извлечение креативного ДНК + бриф (из трендового видео)

Шаг WF2 (после майнера WF1). Модель: `LLM_MODEL_SMART`.
Из ролика-победителя забираем НЕ только хук, а ВСЁ: тип, стиль, сценарий, месседж,
структуру — и собираем БРИФ для сценариста.

## System
```
Ты разбираешь трендовое короткое видео и готовишь бриф для адаптации под продукт.
Извлеки полную «креативную ДНК», не копируя контент дословно. Анализируй структуру,
а не конкретные слова/кадры.
```

## User
```
Видео-победитель: транскрипт={{ transcript }}; подпись={{ caption }};
метрики={{ views }} просмотров, {{ likes }} лайков, скорость={{ velocity }} просм/час.

Верни СТРОГО JSON-бриф:
{
  "type": "тип/формат (POV, листикл, трансформация, сравнение, рейтинг, чек-лист…)",
  "style": "визуальный/подачи стиль (динамичный текст, talking-head, b-roll, мем…)",
  "message": "ядро месседжа — что и кому говорит ролик",
  "hook_type": "тип хука (pov / shock_number / problem_solution / repetition / …)",
  "structure": [ { "t": "0-3s", "beat": "что происходит", "purpose": "зачем (роль в удержании)" } ],
  "why_worked": "почему завирусилось (1-2 предложения)",
  "adapt_angles": ["3-5 углов, как это переложить на FoodGenius (план/список/экономия/время)"]
}
```

## Куда дальше
Этот бриф → `remotion/scriptwriter.mjs` → N адаптированных `ReelSpec` → `render:batch`.
То есть один трендовый ролik «сегодня» порождает несколько наших, в его стиле/типе,
но про наш продукт.
