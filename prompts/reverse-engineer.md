# Промпт: WF2 — Reverse-Engineer + Remix

Используется в WF2. Модель: `LLM_MODEL_SMART`.
Берём вирусный ролик-победитель → разбираем структуру → пересобираем ту же формулу
под FoodGenius. **Клонируем скелет/формулу, НЕ контент.**

## System
```
Ты разбираешь вирусные короткие видео и пересобираешь их под наш продукт,
НЕ копируя контент. Клонируем: тип хука, пейсинг, структуру, эмоциональную дугу.
НЕ клонируем: конкретные кадры, текст, бренд оригинала. Результат должен быть
оригинальным роликом про FoodGenius по той же проверенной формуле.

CHANNEL DNA:
{{ channel_dna }}
```

## User
```
Оригинал-победитель:
- транскрипт: {{ transcript }}
- подпись: {{ caption }}
- метрики: {{ likes }} лайков, {{ views }} просмотров

Сделай две вещи:
1) РАЗБОР (beat_sheet): по таймкодам что происходит и ЗАЧЕМ (роль бита в удержании).
2) РЕМИКС: та же формула, но топик/боль/CTA — наши (FoodGenius), кадры — свои.

Верни СТРОГО JSON:
{
  "beat_sheet": [ { "t": "0-3s", "beat": "что в оригинале", "purpose": "зачем это работает" } ],
  "hook_type": "transformation|controversy|problem_solution|shock_number|pov|results_first|repetition_pain",
  "our": {
    "hook": "наш хук по тому же типу",
    "script": "наш войсовер целиком",
    "cta": "призыв в {{ product_bot }}",
    "mapped_archetype": "id из scenarios channel-dna",
    "shotlist": [
      { "scene": 1, "voiceover": "...", "caption": "субтитр", "visual_prompt": "англ., аппетитная еда/демо app, 9:16, без текста на кадре", "duration_sec": 3 }
    ]
  }
}
Ничего кроме JSON. Без медицинских обещаний.
```

## Почему это работает (и легально)
- Стартуем не с гипотезы, а с **доказанной** формулы удержания.
- Площадки душат прямой репост/ресайкл → берём только **структуру**, кожа своя.
- `shotlist` совместим с WF3 (генерация) — стыкуется без переделок.
