# Расписание: 3 слота в день, ограниченный объём

«Посты и видео» — завод чередует видео-ролики и текстовые посты, **по 1 единице в слот**, 3 раза в день (Москва):

| Слот | Время (МСК) | Формат | что выходит | cron |
|------|-------------|--------|-------------|------|
| Утро | **08:00** | `demo` | промо-видео | `0 8 * * *` |
| День | **12:30** | `text` | текст: Threads (коротко/провокационно) + Instagram (карточка) | `30 12 * * *` |
| Вечер | **17:50** | `creator` | UGC-видео (ИИ-персонаж) | `50 17 * * *` |

- **Видео** (`demo`/`creator`): майнинг трендов → бриф → сценарист → рендер → публикация (YouTube/IG/Threads).
- **Текст** (`text`): аналитика Threads → короткие провокационные посты → Threads (чистый текст) + Instagram (карточка-картинка). См. `docs/09-text-posts.md`.

«Ограниченный объём» = аргумент `N` (по умолчанию **1**). Форматы и время тасуются как угодно (см. ниже).

## Вариант A — cron (работает сразу, без n8n)

Ключи берутся из `.env` в корне репозитория (создать из `.env.example`, в git не коммитится).

```bash
# 1) убедись, что .env заполнен (ENSEMBLEDATA_TOKEN, DEEPSEEK_API_KEY, BLOTATO_API_KEY, BLOTATO_ACCOUNTS)
# 2) поправь путь к репозиторию в deploy/crontab, если он не /home/user/contentzavod2
# 3) установи расписание
crontab deploy/crontab
crontab -l          # проверить
tail -f logs/zavod_$(date +%F).log   # смотреть прогон
```

Ручной прогон одного слота (для теста):
```bash
tools/scheduled_run.sh test creator 1
```

`scheduled_run.sh <slot> <demo|creator> <N>` — грузит `.env`, запускает `run_pipeline.sh N FORMAT`,
пишет лог в `logs/`. Если ключей нет — слот падает с понятной ошибкой (зря не крутит).

## Вариант B — n8n (Schedule Trigger)

В каждом из 3 расписаний — нода **Schedule Trigger** с cron-выражением из таблицы выше
(в настройках n8n `GENERIC_TIMEZONE=Europe/Moscow`, уже задано в `docker-compose.yml`),
далее **Execute Command**:
```
FORMAT=creator tools/scheduled_run.sh noon creator 1
```

## Менять частоту / объём / форматы

- **Больше роликов в слот:** последний аргумент, напр. `… noon creator 2`.
- **Только промо или только UGC:** поставь нужный формат во всех строках `deploy/crontab`.
- **Другое время:** правь поля cron (минуты/часы) — время в МСК (`CRON_TZ=Europe/Moscow`).
- **Пауза:** `crontab -r` (снять расписание) или закомментируй строку `#`.

## Форматы

- **`demo`** — динамичный промо-ролик (боль → НАДОЕЛО → демо приложения → выгоды → CTA). Композиция `DemoReel`.
- **`creator`** — UGC «блогер/ИИ-персонаж рассказывает в камеру», на экране web app, крупные субтитры. Композиция `CreatorReel`.
- **`text`** — текстовые посты: Threads (короткий провокационный пост по аналитике) + Instagram (карточка-картинка `TextCard` + подпись). См. `docs/09-text-posts.md`.

Видео всегда несут ссылку `t.me/foodgenius_ai_bot` в кадре (вотермарка + плашка CTA); текст и подписи — в тексте поста.
