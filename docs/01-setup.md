# Установка и запуск

## 0. Предусловия
- Docker + docker compose
- Заполненные ключи (см. `02-credentials.md`)
- Google-таблица по схеме из `03-google-sheets.md`

## 1. Поднять n8n
```bash
git clone <repo> && cd contentzavod2
cp .env.example .env
# отредактируй .env — впиши ключи
docker compose up -d
```
n8n: http://localhost:5678 (при первом входе создаёшь админ-аккаунт).

## 2. Завести credentials в n8n (UI → Credentials)
Часть ключей воркфлоу читают из `$env` (проброшены через docker-compose),
но для Google Sheets и Telegram нужны полноценные n8n-credentials:

| Credential               | Тип в n8n                  | Где используется |
|--------------------------|----------------------------|------------------|
| Google Sheets account    | Google Sheets OAuth2 / SA  | все WF (чтение/запись очереди) |
| Telegram account         | Telegram API (bot token)   | WF7 (дайджест/kill-switch) |
| (опц.) HTTP Header Auth  | Header Auth                | если не хочешь использовать `$env` |

> Остальное (Anthropic, fal.ai, Creatomate, upload-post) воркфлоу берут из
> `$env.*`. Хочешь хранить их как n8n-credentials — замени в HTTP-нодах
> `={{ $env.XXX }}` на соответствующий credential.

## 3. Импортировать воркфлоу
n8n → Workflows → Import from File → по очереди все файлы из `workflows/`.
После импорта в каждом воркфлоу:
1. Открой ноды с предупреждением «credential not found» → выбери свой credential.
2. Проверь, что `GOOGLE_SHEET_ID` / таб подхватились из `$env`.

## 4. Порядок запуска (рекомендация)
Включай воркфлоу постепенно — проверяя каждый этап:

1. **WF5 (Публикация)** первым на готовом MP4:
   вручную добавь в Sheets строку `status=produced`, заполни `video_url` +
   тексты — убедись, что публикация на 3 площадки летит. Это MVP.
2. **WF4 (Тексты)** — добавь строку `produced` без текстов, проверь автогенерацию.
3. **WF1+WF2** — проверь генерацию идей и сценариев.
4. **WF3 (Генерация видео)** — самый дорогой, включай с маленьким бюджетом.
5. **WF6 (Аналитика) + WF7 (Дайджест)** — замыкаем цикл.

## 5. Активация (автопилот)
Когда каждый этап проверен — переключи воркфлоу в **Active**.
Cron-триггеры начнут сами тянуть очередь. WF7 утром пришлёт дайджест
«сегодня выйдет …» с кнопкой 🚫 стоп.
