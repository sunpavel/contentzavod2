# Креативный сценарист: тренд → бриф → N адаптированных роликов

Не «подмена хука», а **полная креативная адаптация**: из трендового ролика забираем
весь сценарий/тип/стиль/месседж → бриф → внутренний ИИ-сценарист плодит несколько
наших роликов в том же стиле, но про продукт (бот + web app).

## Конвейер

```
WF1 Viral Miner ──► WF2 Извлечение ДНК ──► Сценарист ──► render:batch ──► WF4/WF5
(трендовые видео   (тренд → БРИФ:          (бриф → N        (N MP4)        тексты+
 по скорости)       тип/стиль/месседж/      ReelSpec под                    публикация)
                    структура)              наш продукт)
```

| Шаг | Чем | Файл |
|-----|-----|------|
| Майнинг трендов | **EnsembleData** (TT+IG, velocity) | `tools/mine_ensembledata.mjs` → `mining/winners.json` |
| Извлечение ДНК + бриф | LLM | `prompts/trend-extract.md` |
| Сценарист (бриф → N спек) | LLM | `remotion/scriptwriter.mjs` + `prompts/scriptwriter.md` |
| Рендер | Remotion | `npm run render:batch` |

Майнер (живой пример прогона `2026-06-18`):
```bash
ENSEMBLEDATA_TOKEN=... node tools/mine_ensembledata.mjs "чтоприготовить,рецепты,ужин" "что приготовить"
# → топ-10 победителей по просмотрам/час (TikTok), ~6 юнитов
```
EnsembleData — основной источник (TT+IG, отдаёт velocity сам); Apify — фолбэк.
Пример брифа из реального тренда: `mining/brief_example.json`; адаптации сценариста:
`props/gen_dinner.json` («что на ужин»), `props/gen_quick.json` («лень готовить»).

## ReelSpec — что варьирует сценарист

Шаблон `DemoReel` полностью управляется спекой (не только хук):

```jsonc
{
  "hook": [{ "label": "...", "line": "...", "size": 150 }, { ... }],
  "capOnboarding": "подпись над онбордингом",   // месседж
  "capMenu": "подпись над меню/планом",         // месседж
  "benefit": ["строка", "строка", "акцентная"], // выгоды/посыл
  "ctaTitle": "две строки\nпризыва",
  "accent": "#34D399",                          // настроение/стиль
  "saveText": "Сохрани, чтобы\nне потерять",      // save-триггер (опц.)
  "music": false                                // true → подмешать public/music.mp3
}
```

Звук: для TikTok/IG лучше добавлять трендовый аудио на площадке (сигнал ранжирования).
Запекать музыку (`music:true` + `remotion/public/music.mp3`) имеет смысл скорее под YouTube Shorts.

Продуктовый payoff (реальная запись приложения) — **фиксирован** (это наш моат),
а сценарий/месседж/стиль/CTA адаптируются под каждый трендовый ролик.

## Запуск (когда есть ключи)

```bash
# 1) майнер собрал трендовые видео (WF1, Apify) → для каждого получили БРИФ (trend-extract)
# 2) сценарист: бриф → N адаптированных спек
cd remotion
ANTHROPIC_API_KEY=... node scriptwriter.mjs ./briefs/today.json 3
# 3) рендер всех спек
npm run render:batch
```

## Примеры (сделаны вручную как «сценарист»)
`props/gen_ai.json` (угол «AI решает за тебя») и `props/gen_save.json`
(угол «хватит выкидывать деньги») — одна и та же запись продукта, но разный
месседж/стиль/акцент. Рендеры: `assets/reel_gen_ai.mp4`, `reel_gen_save.mp4`.

## Честно про границы
Шаблон остаётся **product-demo** (наш сильный формат). Сценарист адаптирует угол/
месседж/стиль/хук под тренд — но не воспроизводит произвольные форматы (танцы и т.п.).
Для более глубокой структурной вариативности (разные типы сцен) — следующий шаг:
расширить спеку до списка произвольных сцен.
