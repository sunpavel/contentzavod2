# Threads: ветки, которые разгоняет алгоритм

Threads ранжирует по реакции в **первый час**: лайки, комменты, сохранения, репосты.
Поэтому завод постит не одиночный пост, а **ветку** (несколько связанных твитов) с такой структурой —
её разгоняет алгоритм без рекламы.

## Структура ветки (ПРОМПТ 4)
1. **Хук = боль.** Первый твит — чистая боль/разрыв шаблона ЦА, ≤12 слов, без раскачки. Листать невозможно.
2. **Команда сохранить.** Второй твит даёт ранний сигнал ценности: «Сохрани, чтобы не потерять» + что внутри.
3. **Автономные твиты.** Каждый твит самостоятелен — вырви любой, он несёт законченную мысль (репостят отдельно). Конкретика: цифры, шаги, примеры.
4. **Ссылка на бота** — предпоследним постом (не в хуке, чтобы не резать охват).
5. **Финал = вопрос, который невозможно проигнорировать.** Острый/личный выбор → комменты в первый час → разгон.

Ветка **заканчивается вопросом**, ссылка идёт перед ним — так финал работает на реакцию.

## Как это собирается
```
run_target <ниша> threads
  └─ gen_thread.mjs   → ветка из 6-8 твитов (критик-рефайн ≤2, рубрика виральной ветки)
       └─ critic.scoreThread  → где теряется реакция (ПРОМПТ 3) + паттерны залетевших (ПРОМПТ 5)
       └─ sanitize.mjs        → бренд-гард: ни одного вульгаризма (иначе чистая переписка / пропуск слота)
  └─ вставка ссылки предпоследним постом (ref-код ?start=th-<ниша>)
  └─ publish_blotato (BLOTATO_THREAD_FILE) → ветка через content.additionalPosts[] (Blotato сам сцепляет в ответы)
```

| Файл | Роль |
|---|---|
| `tools/gen_thread.mjs` | генерация ветки под нишу (ПРОМПТ 4) |
| `tools/critic.mjs` → `scoreThread` | оценка/правка ветки (ПРОМПТ 3 + 5) |
| `tools/sanitize.mjs` | защита бренда от мата/вульгаризмов |
| `tools/publish_blotato.mjs` | публикация ветки (`additionalPosts`) |
| `tools/threads_doctor.mjs` | ручной разбор охватов (ПРОМПТ 3/5/6) |

## Доктор веток — разбор охватов вручную
Когда накопятся ветки с охватами, прогоняй промпты залетающих авторов:

```bash
# ПРОМПТ 3 — почему ветка не залетела: где теряется реакция, переписать хук и финал
node tools/threads_doctor.mjs fix      thread.json

# ПРОМПТ 5 — паттерны: 3 общих элемента залетевших, как повторить в любой нише
node tools/threads_doctor.mjs patterns winners.json

# ПРОМПТ 6 — восстановить охваты: что изменилось, где потерян алгоритм, 3 действия
node tools/threads_doctor.mjs reach    last5.json
```

Формат входа:
- `fix` — одна ветка: `{"hook":"...","posts":["твит 1","твит 2","..."]}`
- `patterns` / `reach` — массив веток с охватами:
  `[{"posts":["..."],"reach":12000,"likes":340,"comments":58,"date":"2026-06-20"}, ...]`

## Почему это работает
- **Ветка > одиночный пост:** больше поверхности для реакции, дольше удержание в треде, выше шанс комментов в первый час.
- **Автономные твиты** репостят и цитируют по отдельности → внешние входы в ветку.
- **Финал-вопрос** прямо провоцирует комментарии — главное топливо алгоритма.
- **Ссылка не в хуке** → первый твит не штрафуется за внешнюю ссылку, охват выше.
