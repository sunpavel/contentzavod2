# Воронка: показ → клик → /start → юзер бота

Контент даёт охват, но юзеры приходят только если **путь в бота без трения** и мы **видим источник**.

## Ref-коды (атрибуция «откуда пришёл»)
Каждая ссылка несёт метку площадки+ниши: `t.me/foodgenius_ai_bot?start=<плат>-<ниша>`
(`yt`/`ig`/`th`/`tt`). Когда юзер жмёт — Telegram шлёт боту `/start yt-family`.
**Бот должен залогировать этот параметр** (в твоём n8n уже был паттерн `?start=ref_…`).
Тогда в аналитике бота видно, какая площадка и ниша реально приводят людей — и ротацию можно крутить
по КОНВЕРСИЯМ, а не по просмотрам.

| Площадка | Где ссылка | Кликабельна? |
|---|---|---|
| YouTube | в описании ролика (авто ref-код) | да |
| Threads | в тексте поста (авто ref-код) | да |
| Instagram | **только в шапке профиля** | в подписи — НЕТ |
| TikTok | **только в шапке профиля** | в подписи — НЕТ |

## Настроить ОДИН раз на профилях (это критично для конверсии)
Это делается руками в каждом аккаунте:

1. **Instagram** → редактировать профиль → «Сайт» (bio link):
   `https://t.me/foodgenius_ai_bot?start=ig`
   (в подписях мы уже пишем «ссылка в профиле»).
2. **YouTube** → настройки канала → ссылки/описание:
   `https://t.me/foodgenius_ai_bot?start=yt`
3. **TikTok** (когда сделаешь постящий аккаунт) → bio link:
   `https://t.me/foodgenius_ai_bot?start=tt`
4. **Threads** → bio: `t.me/foodgenius_ai_bot?start=th` (плюс в постах ссылка кликается).

Везде один аватар/бренд, в био — короткая выгода + стрелка на ссылку.

## Что это даёт
- IG/TikTok-юзеры получают **рабочий путь** в бота (раньше ссылка в подписи не кликалась — тупик).
- По ref-кодам видно, **что конвертит** → следующий шаг: завязать веса ротации на регистрации в боте
  (нужен экспорт «сколько /start по каждому коду» из бота — это уже на стороне n8n/бота).

## Честно про скорость
Воронка убирает дыры, но первые юзеры на новых аккаунтах = охват, а он копится неделями.
Ускоряет: трендовый звук на площадке, стабильный объём и небольшой **платный посев/промо** на старте.
