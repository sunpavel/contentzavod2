# Стартовый тест-батч — 6 роликов через разные корзины

Цель: дёшево понять, какая **корзина воронки** работает у аудитории FoodGenius,
а не штамповать один архетип. ~12–20 сек, вертикаль, читаются без звука.
Формула: боль/польза в первые 3с → (демо app, если конверсия) → цифра → save → CTA.

---

## 🔴 КОНВЕРСИЯ

### V1 — «Гречка» (боль: однообразие)
```
0–3с   [гречка, смэш-каты] «Пн — гречка» «Вт — гречка» «Ср…» 🥱
3–4с   [стоп] «НАДОЕЛО.»
4–9с   [скринкаст app] меню разных блюд листается
9–12с  [выгода] «Готовые рецепты. 15 минут. ~150₽ порция»
12–14с [save] «Сохрани, чтоб не есть одно и то же»
14–15с [CTA] «Бот в профиле 👆»
```

### V2 — «Опять доставка» (боль: деньги)
```
0–4с   [холодильник→телефон→доставка] «Не знал что приготовить» → «−850₽» → «и так каждый день»
4–5с   [стопка чеков, стоп] «НАДОЕЛО ПЕРЕПЛАЧИВАТЬ?»
5–10с  [скринкаст app] план недели + список покупок с ценой
10–13с [цифра] «Неделя еды = 1500₽. Дешевле 3 доставок»
13–14с [save] «Сохрани перед следующим заказом»
14–15с [CTA] «Считает за тебя → бот»
```

### V3 — «Выкинул продукты» (боль: фудвейст)
```
0–4с   [достаёшь испорченное → в мусор] «Купил» → «забыл» → «выкинул на 1000₽»
4–5с   [хлопок крышки, стоп] «НАДОЕЛО ВЫКИДЫВАТЬ?»
5–10с  [скринкаст app] список покупок ровно под план
10–13с [выгода] «Покупаешь только нужное. 0 в мусор»
13–14с [save] «Сохрани, чтоб не выкидывать снова»
14–15с [CTA] «План + список → бот»
```

---

## 🔵 ОХВАТ

### V4 — «POV: холодильник» (relatable, без продукта)
Чистый охват — проверяем, цепляет ли боль саму по себе.
```
0–3с   [открываешь холодильник, тот же кадр × несколько раз] «POV: открыл холодильник 5-й раз»
3–8с   [закрыл, лёг на стол лицом] «еда так и не появилась»
8–12с  [текст крупно на фоне] «а готовить лень. и идей ноль.»
12–14с [мягкий тег, без впаривания] «знакомо? 🙃 (план питания — в профиле)»
```
> Продукта почти нет. Цель — репосты «это про меня» и комментарии.

### V5 — «5 ужинов до 200₽» (листикл-сохраняшка)
Save-bait, польза вперёд.
```
0–3с   [тарелка крупно] «5 ужинов дешевле 200₽ каждый 👇»
3–11с  [быстрая нарезка 5 блюд] «1… 2… 3… 4… 5» + название/цена
11–13с [текст] «Сохрани, чтоб не думать всю неделю»
13–15с [мягко] «А весь план + список соберёт бот»
```

---

## 🟡 ДОВЕРИЕ

### V6 — «Учим бота» (building in public)
Прозрачность = доверие (тактика Sizzle).
```
0–3с   [экран с перепиской] «Просил бота: "что-нибудь без лука"»
3–8с   [показываешь как бот сначала не понимал] «раньше он не догонял 😅»
8–12с  [демо: теперь учитывает] «научили — теперь убирает лук из всех рецептов»
12–15с [честно] «делаем продукт открыто. подписывайся — покажу что дальше»
```
> Цель — подписка и доверие, не прямая продажа.

---

## Что меряем
После публикации смотрим по корзинам (WF6 → `perf_score`):
- 🔵 охватные (V4–V5): досмотры, репосты, охват
- 🟡 доверие (V6): сохранения, подписки
- 🔴 конверсия (V1–V3): клики/переходы в бота

Победившую корзину — масштабируем, проигравшую — душим. Это и есть петля обучения.
