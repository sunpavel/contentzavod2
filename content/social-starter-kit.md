# Стартовый набор соцсетей — FoodGenius

Чтобы быстро создать аккаунты и подключить к Blotato. Всё единообразно под бренд.

## Айдентика (готова)
- **Аватар:** `assets/brand/avatar-512.png` (чефская шапка, тёмно-бирюзовый) — для всех площадок.
- **Баннер:** `assets/brand/banner-1200x675.png` (для IG/обложек; для YouTube-шапки нужен 2048×1152 — можно увеличить/перерисовать).
- **Цвета:** тёмный фон + бирюза/зелёный (как в приложении и роликах).

## Ники (единый бренд; подбери свободный вариант)
`foodgenius.ai` · `foodgenius_ai` · `foodgenius.app` · `getfoodgenius`
- **Display name:** `FoodGenius — AI план питания`

## Ссылка (link-in-bio)
Везде ведём в бота: **`t.me/foodgenius_ai_bot`**
- TikTok/IG — ссылка в профиле; в подписях к роликам дублируем «бот в профиле».
- YouTube — ссылка в описании канала + в описании каждого Shorts.
- (опц.) Linktree/Taplink, если нужно несколько ссылок.

## ✅ Чек-лист: создать аккаунты → подключить к Blotato
1. **TikTok** — создать аккаунт; в настройках перевести в **Business** (аналитика).
2. **Instagram** — создать; **обязательно перевести в Business/Creator и привязать к Facebook-странице** — без этого автопостинг по API (а Blotato публикует через Graph API) не работает.
3. **YouTube** — создать канал (лучше Brand Account).
4. Поставить аватар (`avatar-512.png`) + баннер, заполнить био/описание, вставить ссылку на бота.
5. **Blotato → Add Account** → подключить каждую площадку через OAuth.
6. Скинуть мне рабочий **BLOTATO_API_KEY** → я вытащу id аккаунтов (`tools/blotato_accounts.mjs`) и запущу публикацию.

## Каденс на старте
- 1–3 ролика в день на площадку (у нас контент уже наштампован — пайплайн делает пачками).
- Первую неделю — смотрим, какие боли/углы заходят (петля WF6 потом автоматизирует веса).

## 🔴 Главный нюанс
**Instagram для автопостинга = Business/Creator + привязка к FB-странице.** Это единственная «бюрократия» на старте; TikTok/YouTube подключаются проще.
